# Jev 的三種判斷類型

Jev 不生成文字。你給它一段狀態和一個問題，它回傳**帶機率的答案**，程式直接拿來用。共三種問法。

## Choice — 「是哪一個」

在互斥選項中挑一個，各選項機率**總和為 1**。

它回答的是「硬要選就選這個」，**不是**「這個標籤成不成立」。一定要放一個 `other`，否則不合的東西會被硬塞進某一類。

## Noul — 「成不成立」

是非題，回傳一個 0～1 的機率，沒有額外的 confidence。

各題**互相獨立，總和不必為 1**，可以全高或全低。注意 0.5 是「是與否各半」，**不是「中等程度」**。要程度請用 Score。

## Score — 「程度多少」

在有序等級上定位，回傳期望值（可能落在整數之間）。

每個等級要**描述具體情境**，只寫「小／中／大」沒有用。

## 怎麼選

| 你要的答案 | 用 |
| --- | --- |
| 互斥選項中的一個 | Choice |
| 某條件成不成立 | Noul |
| 連續軸上的位置 | Score |
| 多個標籤可能同時成立 | 每標籤一個 Noul |

## 三個容易踩的坑

**1. Choice 和 Noul 的門檻不能互換。** 實測同一個標籤：Choice 給 0.65，Noul 給 0.10。前者說「相對最像它」，後者說「其實不成立」。

**2. Score 的期望值不能反推實際數字**，只能拿來比門檻。

**3. 想知道答案可不可信，看該題自己的 confidence，別另外加一個 Noul 當閘門。** 那個 Noul 只會回答它字面問的事。實測加了之後 8 筆送審 6 筆，完全沒有鑑別力。

## 實測表現

**記帳分類**：8 筆分類全對。confidence 準確挑出屈臣氏（0.68）和 7-11（0.60）這兩筆真正跨類別的，其餘都接近 1.00。

**任務規模**：從「買牛奶」0.03 到「重寫整個報表系統」3.00，單調且分得開，直接拿 1.5 當門檻就能用。
